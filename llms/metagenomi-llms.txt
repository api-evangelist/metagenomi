# Metagenomi

> Metagenomi Therapeutics, Inc. (Nasdaq: MGX) is an Emeryville, California clinical-stage
> genetic medicines company. It mines metagenomics — DNA sequenced directly from
> environmental microbial communities — with machine learning to discover novel gene-editing
> machinery, then engineers it into in vivo genome-editing therapies. Its product is a drug
> pipeline. It is not a software or API company.

## Important for agents

Metagenomi publishes **no API, no SDK, and no machine-readable specification of any kind**.
There is no developer portal, no documentation site, no OpenAPI/AsyncAPI/GraphQL/MCP surface,
no webhooks, no `/.well-known/` document, and no agent card. Do not attempt to construct or
call a Metagenomi API endpoint — none exists. This file was generated by API Evangelist from
the company's public website; it is not published by Metagenomi.

- Probed 2026-08-25: `/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`,
  `/api-docs`, `/docs`, `/redoc`, `/graphql`, `/api`, `/llms.txt` and every
  `/.well-known/*` path on metagenomi.co all return HTTP 404.
- `api.`, `dev.`, `developer.`, `docs.`, `app.`, `platform.`, `portal.` and `status.`
  .metagenomi.co do not resolve. `data.metagenomi.co` resolves to an AWS load balancer that
  accepts no public connection.

## Technology platform

Metagenomi's published gene-editing toolbox spans five system classes:

- Programmable CRISPR nucleases — thousands of nucleases for site-specific knock-in or knock-down
- Ultra-small systems — nucleases compact enough to package into a single AAV vector
- Base editors — described by the company as "the smallest CRISPR base editors known"
- RNA Mediated Integration Systems (RIGS) — edits encoded in RNA templates
- CRISPR Associated Transposases (CASTs) — gene integrations exceeding 10,000 base pairs
